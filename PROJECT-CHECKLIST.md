# Carolinas Mexican Kitchen — Website Checklist

**Goal:** Finish, test, and get owner approval for a professional website.

**Rule:** Mark a task complete only after you have tested it. Keep owner questions in the separate list at the bottom.

## 1. Finish the pages

### Home

- [ ...] Fix overlapping text, images, or clipped sections.
- [ ] Test the hero slider and navigation menu.
- [ ] Check hours, location, phone, and main calls to action.

### Menu

- [ ] Confirm menu names, prices, descriptions, and photos.
- [ ] Check layout on phone and desktop.
- [ ] Test any order buttons or links.

### Reservations

- [ ] Add and test the approved reservation or waitlist link.
- [ ] Make the next step clear if the restaurant uses an external service.

### Catering

- [ ] Add approved catering information.
- [ ] Provide a working way to contact the restaurant about catering.

### Careers

- [ ] Add approved hiring information.
- [ ] Provide a working application or contact method.

### FAQ

- [ ] Add answers approved by the owner.
- [ ] Check spelling and make answers easy to scan.

## 2. Test the whole site

- [ ] Test every internal navigation link.
- [ ] Test all third-party ordering, delivery, reservation, and waitlist links.
- [ ] Check that phone and map/address links work.
- [ ] Test on a phone, tablet-sized screen, and desktop.
- [ ] Check for broken images, broken links, horizontal scrolling, and overlapping content.
- [ ] Navigate using only the keyboard; check that focus is visible and buttons/links can be used.
- [ ] Add useful alt text to meaningful images.
- [ ] Check each page has a clear title and a unique meta description.
- [ ] Repeat key tests on the published website, not just locally.

## 3. Get ready to launch

- [ ] Fix launch-blocking issues found during testing.
- [ ] Get the owner's approval of the content, prices, photos, links, and final design.
- [ ] Confirm the published URL and HTTPS work.
- [ ] Write down how to make future updates and who will maintain the site.

## Waiting for owner confirmation

- [ ] Current menu, prices, and item availability.
- [ ] Business hours, address, and phone number.
- [ ] Correct third-party ordering and delivery links.
- [ ] Reservation/waitlist service and link.
- [ ] Catering details and inquiry process.
- [ ] Careers application process.
- [ ] FAQ answers and final website approval.

## Finish line

The project is finished when all six pages are complete, approved business information is accurate, customer links work, mobile and keyboard checks pass, the published site is tested, and the owner approves it.

**Scope note:** Use the restaurant's third-party services for ordering, delivery, and reservations. Don't build a custom ordering or booking system unless the owner asks for one.
